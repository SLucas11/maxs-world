# Max's World

An island life with friends. Play as Max on your own island.

**Play / install:** https://slucas11.github.io/maxs-world/

- Android: open the link in Chrome, then tap **Install app** on the title screen (or the ⋮ menu, then **Install app**).
- iPhone: open the link in Safari, tap **Share**, then **Add to Home Screen**.

The app works offline and shows an "Update now" banner when a new version is published.

Third-party: three.js r128 (MIT, `lib/three-LICENSE.txt`), Fredoka font (SIL OFL, `lib/fredoka-OFL.txt`).
